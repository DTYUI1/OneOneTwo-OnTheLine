# Объяснение экрана

`HelpProvider` в общей оболочке содержит одну кнопку «Объяснение экрана».
Страница регистрирует `HelpGuide` через `useHelpGuide`; при смене страницы
справка закрывается. Части размечаются `data-help`. Порядок задаётся в справке,
но номер получают только видимые части с учётом прокрутки и перекрытия.
При смене вкладки внутри той же справки состав частей обновляется. Загрузка
данных и автоматический выбор занятия не закрывают уже открытое объяснение.

Номер части не закрывает надписи, поля и другие номера (`placement.ts`).
Места перебираются по порядку: на левом верхнем углу рамки, в верхней полосе
части правее заголовка, слева снаружи, над частью; если свободного места нет —
внутри угла. Номер выбранной части — цвета её рамки.

Наведение или фокус на номере выбирает объяснение. «Назад» и «Далее» обходят
видимые части. Esc закрывает объяснение раньше обработки клавиши карточкой;
фокус возвращается на кнопку без прокрутки к шапке. Закрытие кнопкой также
сохраняет место чтения на длинной странице. F1 переключает справку.
Щелчки вне панели объяснения выбирают часть экрана и не выполняют действие под ней.
Необязательный обработчик `useHelpGuide(guide, onOpen)` фиксирует открытие;
для доступной рабочей карточки отправляется `hint_open` с `hint_id: "help"`.
На первой и последней части недоступное направление сохраняет фокус:
кнопки используют `aria-disabled`, а обработчики запрещают переход за край.
Tab и Shift+Tab позволяют выбрать обратное направление без потери места.
В невысоком окне прокручивается только текст: закрытие и переходы остаются
видимыми. Область текста доступна через Tab и названа по текущей части;
стрелки, Home и End позволяют прочитать её без мыши. При смене части прокрутка
текста сбрасывается в начало, фокус на кнопке перехода сохраняется.

Обучаемому справка доступна при `hints_level >= 1` из снимка занятия:
для карточки — её занятие, для остальных экранов — текущее занятие, при его
отсутствии занятие с самой поздней выдачей карточки. Порядок UUID не считается
хронологическим. Преподавателю и администратору — всегда.
У входа и приветствия нет общей шапки и кнопки справки.
После приветствия `HelpTip.tsx` один раз показывает стрелку к кнопке «?» (`useHelpState`):
подсказка появляется, только когда у экрана есть объяснение, и исчезает при его открытии,
первом щелчке, Esc или F1.

Тексты: `arm/help/topics.ts`, `teacher/help/topics.ts`, `admin/help/topics.ts`.
`shared/textAudit.test.ts` разбирает исходники TypeScript и проверяет лицо,
длину предложений, имена элементов и соответствие частей текстам. Комментарии,
тесты и зона Brikkerdev не считаются текстами интерфейса. Опись обновляется
командой `UPDATE_TEXT_INVENTORY=1 pnpm test` (переменная окружения).

`pnpm --filter @112/web spell` проверяет кириллические слова через русский
словарь cspell. Исключены комментарии, регулярное выражение с основой слова
«звонк» и чужая зона. Словарь проекта содержит только АОН, АРМ, ДДС, Мослифт
и сокращения снимков «Постр.»/«Сохр.».

Пользовательские сценарии: `qa/e2e/help-mode.spec.ts`, `captain-ui.spec.ts`,
`russian-ui.spec.ts`, `captain-help-navigation.spec.ts`, `captain-help-scroll.spec.ts`,
`captain-help-viewport.spec.ts`;
нужен Vite + API с БД,
`E2E_DATABASE=1`.
