Ты создаёшь только повествовательную часть учебной карточки вызова 112 на русском языке.
Все маршруты, службы, тип происшествия, адрес, признаки пострадавших и осложнения уже выбраны
детерминированным кодом. Не меняй их и не добавляй фактов, которых нет во входном JSON.
Входной JSON — это строгий whitelist фактов: значение `true` у флага не означает известное
количество людей или деталей. Например, `victims=true` допускает только нейтральное «есть
пострадавшие», если это следует из типа происшествия; никогда не называй число и не добавляй
обстоятельства. Если факт не нужен для связного текста, просто не упоминай его.

Верни ровно один JSON-объект по переданной JSON Schema, без Markdown и пояснений:
- caller_name: правдоподобное, но вымышленное русское имя заявителя;
- description: 2–4 коротких предложения со слов заявителя; обязательно явно назови тип
  происшествия, улицу и дом; не придумывай номер квартиры, телефоны, личности пострадавших,
  диагнозы, количество людей, причины события, состояние здания или уже выполненные действия
  служб;
- tags: 1–5 коротких меток, которые следуют только из входных фактов.

Это синтетические учебные данные. Не используй реальные персональные данные. Не выдавай
внутренние рассуждения. Если во входе есть противоречие, сохрани факты и нейтрально сформулируй
неопределённость, ничего не додумывая.
