# Озвучка (scripts/voices)

Готовые файлы лежат в `data/voices/`; синтезатор и модели в runtime не нужны. Происхождение
голосов Piper и лицензии — `PROVENANCE.md`.

## Голоса сценариев ДДС (GP-15, TC-09)

Реплики бригад во всех сценариях `data/scenarios/*.json` — набор `data/voices/dds-v3/`:
Vosk TTS (локально, CPU), голос по телефону. Почему Vosk — `docs/voices_tts_comparison.md`.
Прежний набор `dds-v2` (полоса рации) остаётся для уже выданных сценариев.

```sh
scripts/voices/scenario_generate.sh                     # синтез набора dds-v3 в контейнере
python3 scripts/voices/scenario_voices.py switch dds-v3 # сценарии → набор, version + 1
```

Каждая реплика проходит два шага:

- **текст для синтеза** — `sayable.py`: числа словами («дом 24А» → «дом двадцать четыре а»),
  телефоны группами с ведущими нулями, аббревиатуры по буквам (ДТП → «дэтэпэ»), ударения
  омографов из `data/pronunciation.json` («уж+е», «бедр+а»). Правка словаря — `revision + 1`:
  ревизия в ключе кеша, реплики пересоберутся. Тест — `scripts/tests/test_sayable.py`;
- **голос по телефону** — `phone.py`: 8 кГц, полоса 300–3400 Гц, сжатие, μ-law, 250 мс
  открытой линии до и после речи и тихая подложка места: у бригады в пути и на улице — улица,
  на месте в помещении — работы.

Реплики должностных лиц служб («Слушаю вас», «Я вас понял…») — те же файлы Piper через
телефон с подложкой тихого офиса: `python3 scripts/voices/officials_phone.py` →
`data/voices/phone/`, в бандл софтфона едут они. Шипение линии во время разговора
добавляет браузер (`apps/web/src/arm/softphone/tones.ts`, Web Audio, без файлов).

Движок выбирается по окружению:

| Окружение | Движок | Сеть |
| --- | --- | --- |
| `ELEVENLABS_API_KEY` не задан | Vosk TTS 0.3.61, модель `vosk-model-tts-ru-0.9-multi` (Apache 2.0) | только при первой загрузке модели и pip |
| `ELEVENLABS_API_KEY` задан | ElevenLabs, модель `eleven_multilingual_v2` | на каждую реплику |

Ключ ElevenLabs — только в окружении, в git его нет:

```sh
export ELEVENLABS_API_KEY=...            # не записывайте ключ в файлы репозитория
VOICE_SET=dds-el scripts/voices/scenario_generate.sh
python3 scripts/voices/scenario_voices.py switch dds-el
```

Голос службы у ElevenLabs меняется переменной `ELEVENLABS_VOICE_<служба>=<voice_id>`
(`101`, `102`, `103`, `104`, `GKH`, `MOSLIFT`), модель — `ELEVENLABS_MODEL`. Стенду ключ не
нужен: озвучка собирается заранее, приложение берёт готовые файлы и работает без интернета.

Правила набора:

- Набор неизменяем. Seed сверяет SHA-256 с манифестом, а синтез недетерминирован: другой
  голос — это новый набор (`VOICE_SET=dds-v3`), а не перезапись файлов. Повторный запуск
  с тем же набором досинтезирует только новые и изменённые реплики.
- `switch` переводит пути в сценариях на набор и поднимает `version`: выданный план
  неизменяем, новый голос доходит до стенда только новой версией сценария (seed снимает
  прежние версии с выдачи). Без полного манифеста `switch` откажется.
- Новый сценарий или новая реплика: `scenario_generate.sh` с текущим набором, затем
  `switch` с ним же — путь получат только реплики без озвучки.
- Новый набор в сценариях — поменяйте `VOICE_SET` в `apps/api/tests/test_scenario_voices.py`:
  тест проверяет, что каждая реплика озвучена набором и совпадает с манифестом по SHA-256.
- Голос реплики — голос службы сценария (`VOSK_VOICE_OF_SERVICE` в `scenario_synth.py`).
- Полоса рации — фильтр `RADIO` в `scenario_synth.py`: 300–3200 Гц, сжатие, шум эфира,
  150 мс открытой тангенты до и после речи.

## Остальные наборы (Piper)

| Что | Сборка | Файлы |

на него больше не ссылаются.
