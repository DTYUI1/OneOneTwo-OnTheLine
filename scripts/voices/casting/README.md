# Кастинг голосов ElevenLabs

Подобрать голоса бригад и дежурных служб ДДС на слух и получить строку для сборки озвучки
(`scenario_generate.sh` на ветке `feature/dds-gameplay-ai`, задача GP-15).

```sh
python3 scripts/voices/casting/casting.py serve        # http://localhost:8112/casting/ — слушать и выбирать
```

Страница по умолчанию играет запись «в трубке» (полоса 300–3400 Гц, как `phone.py`). Отметки
«беру» хранятся в браузере, внизу страницы собирается `ELEVENLABS_MODEL` и
`ELEVENLABS_VOICE_<служба>`.

Как устроено:

- `roles.json` — кто говорит и какими фразами (настоящие реплики сценариев);
- `cast.json` — кандидаты, по три на роль: наше имя, короткая характеристика, `voice_id`;
- `casting.py shortlist` — кандидаты из библиотеки ElevenLabs (русский): только описания и
  бесплатные превью в `out/previews/`, наш текст на сервер не уходит;
- `casting.py synth` — смета, `synth --go` — озвучить недостающее. Запись лежит в
  `out/cache/<sha256>.mp3`, где хеш берётся от модели, голоса, настроек и текста: та же фраза тем же
  голосом второй раз не отправляется. Новый кандидат или новая фраза — досинтезируется только
  она. `out/voices/<роль>/<имя>/<номер фразы>.mp3` — те же файлы под человеческими именами.

Ключ — `ELEVENLABS_API_KEY` в `.env` в корне репозитория (в git не попадает).
