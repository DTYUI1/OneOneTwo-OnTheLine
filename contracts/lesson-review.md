# Итоги занятия: отзыв ученику, тепловая карта, выдача отчёта — TC-13

Источник: `docs/competitors/touches.md`, «Преподаватель»; разбор — `docs/dds_touches.md`.
Как и `live-lesson.md`, операции не входят в `openapi.json` и ничего не меняют в его схемах.
Тело и ответ — JSON, POST и PUT требуют `X-CSRF-Token`. Только преподаватель-владелец занятия
(чужое — `404`); занятие не должно быть черновиком (`409`).

## Обоснование изменения оценки (`POST /overrides`, схема `OverrideInput`)

`reason` после обрезки пробелов не пуст — иначе `422` и ничего не сохраняется. Схема OpenAPI
не меняется (`minLength: 1` уже есть), проверка строже на сервере.

## Отзыв ученику

`GET /sessions/{id}/review` — `{"trainees": TraineeReview[], "heatmap": Heatmap}`.

`TraineeReview`: `{user_id, full_name, ai_total: number | null, final_total: number | null,
draft: string, text: string | null, released_at: string | null}`.

- `ai_total` — среднее оценки ИИ по последним оценкам попыток ученика, до правок преподавателя;
  `final_total` — то же с правками («оценка ИИ 64 → итоговая 75»). Нет оценок — `null`.
- `draft` — черновик отзыва. Строится на сервере по шаблону из оценок (без сети и модели):
  итог, что получилось лучше всего, что подтянуть (до двух самых слабых критериев). Хранится
  при первом `GET`; пока отзыв не правили и не выдали, каждый `GET` пересобирает его по свежим
  оценкам, после первой правки он замирает — это «было».
- `text` — отзыв после правки преподавателем, «стало»; `null`, пока не правили.

`PUT /sessions/{id}/feedback/{user_id}` — тело `{"text": string}`, после обрезки 1…2000
символов (иначе `422`); `user_id` — участник занятия (иначе `422`). Выданный отзыв править
нельзя (`409`). Ответ `200` — `TraineeReview`.

`POST /sessions/{id}/feedback/release` — «Выдать отчёт»: всем участникам, у кого отзыв ещё не
выдан, ставит `released_at`; ученику уходит `text`, а если его нет — `draft`. Ответ `200` —
`{"released": number}`. Повтор выдаёт только новых.

`GET /feedback` — обучаемый: `[{session_id, text, released_at}]` только по выданным отчётам,
свежие первыми. До выдачи ничего не видно.

Хранение: `lesson_feedback (id, session_id FK, user_id FK, draft, text, released_at)`,
уникально по `(session_id, user_id)`.

## Тепловая карта

`Heatmap`: `{"criteria": string[], "rows": [{user_id, full_name, cells: {<key>: number | null}}],
"advice": string[]}`. Ячейка — средняя оценка критерия по попыткам ученика (с правками), `null` —
не оценивался. Критерий «провален» у ученика, если средняя < 0,5. Если провал у **30 % и более**
оценённых учеников — в `advice` строка совета группе по-русски.
