# Выключатель модуля «Оператор 112» — `GET /api/features`, `PUT /api/admin/features`

Источник: рекомендации организаторов 16.10 (пункт 5: 112 скрыт совсем или включается только
администратором). Как и остальной API модуля 112, эти операции не входят в `openapi.json`.

Настройка хранится на сервере в таблице `settings`, ключ `operator_module`, значение
`{"enabled": bool}`. Строки нет — модуль **выключен**.

## `GET /features`

Без входа в систему: веб читает настройку на экране входа и после него.

Ответ `200`: `{"operator_module": bool}`.

## `PUT /admin/features`

Только роль `admin`, заголовок `X-CSRF-Token` обязателен. Тело: `{"operator_module": bool}`.
Ответ `200` — то же тело. Изменение пишется в `audit_log` (`features_update`).

## Поведение при выключенном модуле

Все операции `/api/operator/*` отвечают `404` с кодом `operator_module_disabled`
(сначала проверка входа и роли: без сессии — `401`). Данные 112 в базе остаются.
