# Визуальная сверка оператора 112

Из корня репозитория, Vite уже работает (`cd apps/web && pnpm exec vite --host 127.0.0.1`):

```sh
node qa/visual/operator/compare.mjs
```

`BASE_URL` переопределяет адрес Vite. Нужны только уже установленные Playwright и Chromium.
API авторизации/health подменяется; модуль, данные, стили, переходы карточки и службы настоящие.
Входящий звонок принимается, проводник выключается, разговор сворачивается обычной кнопкой.
Состояния 01, 02, 04, 03, 06, 07, 08, 09 проходят последовательно; 05 исключён по заданию.

Viewport 2133×1070, deviceScaleFactor 0.9. Из оригинала вырезается `(0,77,1920,963)`.
Canvas делает наложение 50 % и карту разницы. Новых зависимостей нет.

Скрипт фиксирует переменные реквизиты (номер, телефоны, дату и показание секунд),
часы Playwright выбирают реальное состояние таймера. CSS и выбранные отметки не подменяются.
Единственная исключённая область — водяной знак Windows: `(1390,871,460,43)`.
Снимки, эталоны, наложения и карты разницы — `docs/operator_112_review/stage4/`.
`OPERATOR_VISUAL_OUT=docs/operator_112_review/stage4/fixes/visual` сохраняет новый прогон
отдельно от исходных метрик этапа 4. Свёрнутое окно остаётся видимым и входит в сравнение.

Порог: пиксель отличается, если максимальная абсолютная разность RGB **>24**;
допустимая доля **5 %**. `overlay/metrics.json` хранит числитель, знаменатель, долю,
среднюю разность, статус каждого состояния и ошибки страницы. При превышении скрипт
выходит с кодом 1; эталон автоматически не обновляется. Субпиксельное сглаживание
исходника не маскируется, поэтому этот показатель строгий и зависит от системного шрифта.

`font-probe.mjs` — дополнительная диагностика: сравнивает несколько **системных** шрифтов
на трёх фрагментах оригиналов средствами Canvas. Не изменяет приложение или эталоны.
Это подбор близкого начертания, а не определение исходного шрифта.

Учебные состояния на пяти окнах снимает `operator-shots.spec.ts`:

```sh
E2E_DATABASE=1 E2E_BASE_URL=https://127.0.0.1:8443 OPERATOR_SHOTS=1 \
OPERATOR_SHOTS_OUT=docs/operator_112_review/stage4/chromium \
pnpm exec playwright test -c qa/playwright.config.ts --project=chromium 'qa/e2e/operator-.*\.spec\.ts'
```

Для Firefox сменить проект и каталог снимков. Пароль стенда передаётся через
`DEMO_PASSWORD`; не записывать его в отчёт или журналы.
