# Нагрузка T-017b

Нагрузочные замеры C-09 — в [`qa/bench/`](../bench/README.md): одна команда поднимает
изолированный стенд, гоняет класс 23 АРМ, запись в БД, отчёт, 100 пользователей и (с `--llm`)
ИИ-судью, пишет отчёт с целевыми значениями PRD.

Обрыв сети на 30 с проверяется e2e `qa/e2e/realtime-recovery.spec.ts` и тестами очереди
`apps/web/src/shared/ws/outbox.test.ts`. Unit-тест очереди не заменяет сетевое испытание
полного приложения.
