лицензия движка не заменяет лицензию голоса. Модели и синтезатор в runtime не нужны.
Не выдавать тон/тишину/системную озвучку за подготовленные четыре голоса Piper.
Brikkerdev может начинать state machine и Web Audio без реплик; отсутствие файла — graceful.
