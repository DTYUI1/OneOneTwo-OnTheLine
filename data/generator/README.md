# Текстовые основы автономного генератора

`gkh-linear.json` содержит две доверенные линейные учебные задачи ЖКХ из
`1c11ece:data/scenarios/pipe-apartment-gkh-1.json` и
`1c11ece:data/scenarios/pipe-apartment-gkh-2.json`. Источник проверен через `git show`.
В новом каталоге `d43811df` они удалены: вместо них есть задача с котёнком, которой нужен
номер заявителя, добавленный преподавателем. Её обязательный звонок генератор не отключает.

Эти основы читает только `app.seed.generator`, когда для ЖКХ нет самостоятельного шаблона
в переданном каталоге. Обычный seed читает только `data/scenarios`: данные отсюда не
возвращают старые сценарии в каталог и не сохраняют старые UUID. Из основ убраны ссылки на
аудио; все доклады — текст. Адрес, заявитель, номер карточки и эталон создаются тем же
генератором, что для остальных служб. Проверка схемы и связности остаётся общей.

У сгенерированных вариантов нет `outcome` прежней сцены: его адрес и последствия удалённых
событий были бы неверны. Полноценный авторский исход и перенос `task_change` требуют
отдельной смысловой генерации и здесь не заявляются. Канонические сценарии и их записи банка
в `data/scenarios` остаются без изменений.
