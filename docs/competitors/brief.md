## Кто мы

Проект OneOneTwoInTouch — учебный симулятор диспетчера ДДС системы-112 Москвы, хакатон ЛЦТ-2026
(в задачах ЛЦТ — «задача 9 / кейс 09», у нас внутренний код C08). Наша команда — «Артифишл Интележенс»,
вошла в финал вместе с ELABS, Ультратех, Всезнайки, NKDL, Aiskra, IGRA, БЕЗУМЦЫ, Пинг 112, MISIS&MR.DRUN, 5 орят.

Наш скоуп: обучаемый — диспетчер профильной ДДС (101/102/103/104/ЖКХ…), получает готовую карточку от 112,
ставит статусы (Принята / Не принята → Начало реагирования / Отказ / Работы завершены), пишет комментарии,
звонит должностному лицу через симулятор IP-телефонии (TTS-реплики). Роли: админ, преподаватель, обучаемый.
Преподаватель раздаёт задания, видит всех live, переопределяет вердикты ИИ, получает отчёты. Четыре уровня
сложности и адаптивность. Нормативы: 30 с на реакцию, 3 мин на карточку. Работа без интернета и без GPU.
Стек: FastAPI, PostgreSQL, React/TS, Docker Compose, локальная LLM как опция, e2e на Playwright.
Есть дополнительный модуль «Оператор 112»: приём входящего звонка и заполнение карточки.

То, что сделано интересно, а не всё подряд:

1. Скоуп: кого учат — оператора 112, диспетчера ДДС или обоих.
2. Автооценка: баллы, рубрики, эталоны, сравнение с эталоном, объяснение ошибок, нормативы времени.
3. ИИ: какая LLM, локально ли (llama.cpp, Ollama, vLLM), без GPU ли; STT/TTS (Vosk, Whisper, Silero, Piper…);
   роль ИИ — абонент-собеседник, генератор сценариев, оценщик, подсказчик.
4. Телефония и голос: SIP, Asterisk, WebRTC, симуляция звонков, озвучка.
5. Сценарии: источник, генерация, классификатор ЕКП (~1283 типа), сложность, адаптивность.
6. Преподаватель: live-мониторинг, вмешательство, назначение занятий, отчёты, разбор попыток, replay.
7. UI: близость к реальному АРМ, интересные интерфейсные решения, обучение интерфейсу.
8. Сдача: офлайн-установка, Windows-инсталлятор, один docker compose, демо-стенд, документация, презентация,
   видео, тесты.
9. Всё необычное, чего у нас, вероятно, нет.

## Формат отчёта

На русском, сжато, без воды. Для каждого репо:

```
### <owner>/<repo> — https://github.com/<owner>/<repo>
- **Команда:** … · **создан / последний коммит:** … · **коммитов:** … · **стек:** …
- **Скоуп:** оператор 112 / ДДС / оба · **зрелость:** заглушка / прототип / полноценное решение
- **Суть** в две строки.
- **Интересное для нас:** 3–8 пунктов; каждый — что именно и где лежит
  (путь или ссылка https://github.com/<owner>/<repo>/blob/<ветка>/<путь>), без пересказа очевидного.
- **Слабые места / чего нет:** 1–3 пункта, если заметно.
- **Куда смотреть следующему агенту:** 1–3 самых ценных файла или папки.
```

В конце файла — «Топ-находки группы»: 3–6 самых сильных идей из всех репо группы, по строке, с репо.
Пустое, недоступное или не про этот кейс репо — одна строка с причиной.
