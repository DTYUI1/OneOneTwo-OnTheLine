# Прототип: обучение диспетчера ДДС

Кликабельный макет идей из [разбора](../README.md), раздел 6. Всё на заглушках: сервера
нет, бригада и службы — сценарий в браузере. Задача макета — показать, как это будет
ощущаться обучаемому и преподавателю, до того как делать в тренажёре.

## Как открыть

Двойной щелчок по `index.html` (Chrome или Firefox). Лучше в наушниках. Рядом должны
лежать `app.js`, `data.js`, `audio.js` и `proto.css`.

Без звука всё тоже работает: реплики идут субтитрами в окне разговора. Звук
выключается галочкой «Звук» в верхней полосе.

## Что здесь заглушка, а что уже есть в тренажёре

- **Как в тренажёре:** реестр, карточка, полоса служб, строка статуса, телефон с бригадами
  и справочником, ответы служб «Слушаю вас» / «Я вас понял, информация принята», отказы
  ненаправленной бригады, доклады бригад тренировочного сценария «Задымление в квартире».
- **Новое — только в прототипе:** всё из таблицы выше. Проверка доклада и комментария —
  по ключевым словам в браузере; в тренажёре доклад распознаётся речью (faster-whisper
  уже есть в worker) и сверяется оценщиком `evalcore`.
- **Числа исхода** («потеряно около 20 минут») — учебная иллюстрация сценария, не прогноз.
  Цифры в «Почему это важно» — с источниками (UL FSRI, модель Larsen 1993), 18 км между
  Дубнинской и Дубининской — по координатам из Википедии.
- Обучаемые на пульте, класс из 23 человек и прошлые ступени — заглушки.

## Голоса

14 новых реплик бригады (вопрос об этаже, просьба о скорой, «приехали не туда», тревога и
другие) озвучены Piper голосом службы 101 (`denis`, как в `scripts/voices/brigade_texts.py`)
с полосой рации. Остальные реплики — готовые файлы тренажёра из `data/voices/` и
`apps/web/src/arm/softphone/voices/`. Список — `voice/lines.json`, сборка —
`voice/build_audio.py` → `audio.js` (реплики как data URI, чтобы страница открывалась без
сервера).

Пересборка без Docker — нужен Python 3.12 и модели Piper в `scripts/voices/.cache`:

```
python -m venv %TEMP%\pv
%TEMP%\pv\Scripts\python -m pip install piper-tts soundfile numpy
%TEMP%\pv\Scripts\python docs/dds_training_review/prototype/voice/build_audio.py
```

Окружение — в короткой папке: в длинном пути Windows не ставит onnxruntime.

## Проверка

`check.cjs` открывает прототип в Chromium (Playwright из корня репозитория) и проходит смену
как обучаемый: адрес с ошибкой, все вводные, тревога, резервный номер, стоп-кадр, дубль.
Потом заглядывает во все вкладки и снимает скриншоты. Падает, если в консоли страницы есть
ошибки или смена не дошла до конца.

```
node docs/dds_training_review/prototype/check.cjs [папка снимков]
```
