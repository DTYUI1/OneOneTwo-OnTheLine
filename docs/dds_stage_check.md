На `integration/dds-stage` после слияния: pytest с PostgreSQL — 915 passed, веб — 780 passed,

   отдавать признак «на связи сейчас» отдельным полем, а время — только по фактам.
2. **Тест живой бригады противоречит своим часам (#80).** `apps/api/tests/test_live_brigade_flow.py:159`
   берёт последний элемент `messages`, хотя доклады в тесте датированы будущим (`worker_tick(now + …)`),
   а список сортируется по `delivered_at` (`service.py:119`). Каскадом валит ещё 2 теста.
3. **e2e #78 не сходятся с текстом вариантов.** `qa/e2e/captain-practice.spec.ts:241`,

   `qa/e2e/admin-integration.spec.ts:44` (9 весов → 10), `qa/e2e/captain-card-tutor.spec.ts:52`
   (`manualNeeded` → `tutorNeeded`).
4. **Голосом «ДТП с пострадавшими» не засчитывается повод.** Whisper `small` распознаёт «ДТП с» как «ДТПС»,
   а повод ищется по точному слову «ДТП» (`packages/evalcore/evalcore/report.py:105–118`): `choice: no_address`,
   служба переспрашивает адрес, хотя он назван. Обходится словами «произошло ДТП, есть пострадавшие». Касается
   любых коротких аббревиатур перед предлогом.
5. **Реплика без озвучки засчитывается только по «Принял» (#79, #80).** Реплики связки (`audio: null`)
   считаются предъявленными только после кнопки «Принял» (`apps/web/src/arm/softphone/brigade/useBrigade.ts:363–378`).
   Диспетчер, который прочитал тревогу, положил трубку и сразу вызвал 103, получает «ответили позже срока»
   и страховочную реплику «Скорая к бойцу едет?». Для тревоги это меняет оценку. Либо озвучить реплики связки
   (DT-10: «реплики связки — без голоса»), либо засчитывать текст при показе в открытом разговоре.

6. **Тревога без ответа засчитывается как «ответили на вызов» (#80, evalcore; найдено 14.10).**
   Ожидание `answer_call` выполняется первым предъявлением реплики события
   (`packages/evalcore/evalcore/brigade.py`, `_first_action`). Неотвеченная тревога приходит в следующем
   звонке обучаемого бригаде, а без доклада бригады не закрыть «Проведение работ» и «Работы завершены».
   Итог: обучаемый, который не взял тревогу и не вызвал скорую, получает «ответили на вызов через 1:15,
   позже срока» — `late`, и правило «критична только тревога без всякой реакции» (`no_reaction`) не
   срабатывает. У закрытой карточки критическая ошибка по тревоге фактически недостижима, а текст разбора
   неверен: на вызов не отвечали. Варианты: засчитывать `answer_call` только по ответу на входящий вызов
   события; или считать тревогу без звонка в 103/112 к сроку критической, даже если реплику услышали.
   Решение — за автором #80 и капитаном (это правило оценки).
   **Решено 15.10** ([решение](decisions.md), `contracts/scenario-events.md`, «Тревога: критична
   скорая к бойцу»): критично, если после тревоги не вызвали скорую — ответили на вызов или нет;
   неотвеченная тревога в разборе — «реплику услышали через …», не «ответили на вызов».
7. **Время вводной в разборе — UTC (DT-06; исправлено 14.10 в #94, c8d52a1).** `_clock` в
   `brigade.py` печатал `fired_at` в UTC: в вердикте «17:30:20», на доске — «20:30». Теперь МСК (UTC+3).
