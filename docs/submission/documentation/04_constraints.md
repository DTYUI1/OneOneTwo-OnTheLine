# 4. Условия применения и ограничения

## 4.1 Условия

- Решение рассчитано на учебный класс: локальный сервер и до 23 рабочих мест в одной сети,
  без доступа в интернет во время работы. Внешние API не вызываются; ИИ — только локальная
  модель, выключаемая настройкой `AI_PROVIDER`.
- Роль обучаемого — диспетчер ДДС, получающий готовую карточку от оператора 112
  (ответы кейсодержателя от 16.09). Приём входящего звонка заявителя вне рамок.
- Алгоритм работы служб универсальный (решение 24.09); специализация исключений 103/104 из
  памятки не реализуется.
- Методика учебных трёх минут (активная обработка без подтверждённого ожидания) — решение
  команды, а не норматив памятки; 30 секунд до первичного статуса — из памятки ДДС.
- Эталонные ответы к билетам заказчик не предоставляет: эталоны — учебная разметка команды,
  утверждаются преподавателем в студии. Исходного аудио заявителей нет — ошибки ввода адреса
  оцениваются по текстовым данным карточки.

## 4.3 Персональные данные

В учебных данных — только вымышленные ФИО и учебные номера `+7 900 000-…`; в билетах заказчика
телефоны заменены. Записи докладов и материалы хранятся локально, в логи ПДн не пишутся.
