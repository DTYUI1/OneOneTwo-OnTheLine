# Сопроводительная документация · задача № 9, ЛЦТ-2026

Учебный симулятор диспетчера ДДС системы 112. Документация по ТЗ §13 и §18: методы обработки
данных, условия и ограничения, сборка и установка, функциональная и компонентная архитектура,
перечень библиотек, соответствие требованиям.

Экспорт в DOCX и PDF (один файл со всеми разделами):

```sh
uv run python scripts/submission/build_libraries.py     # обновить раздел 5
uv run --with markdown python scripts/submission/export_docs.py
```

Результат — `docs/submission/build/C08_documentation.{docx,pdf}` (в Git не входит).
Нужен LibreOffice (`soffice`) для конвертации HTML → DOCX/PDF с кириллическими шрифтами.

## Описание и три руководства в PDF (рекомендации организаторов 16.10, п. 3)

Документы 08–11 написаны под тренажёр диспетчера ДДС по реальным экранам; снимки — в `img/`.
Каждый собирается в отдельный PDF одной командой, без интернета (нужны pandoc, node и Chromium
Playwright):

```sh
python3 scripts/docs_pdf.py        # docs/submission/build/C08_{1_technical_description,2_admin_guide,3_teacher_guide,4_trainee_guide}.pdf
```

Снимки обновляет `qa/e2e/docs-shots.spec.ts` (запуск — в шапке файла, нужен поднятый стенд).
PDF в Git не входят (`docs/submission/build/` в `.gitignore`).
