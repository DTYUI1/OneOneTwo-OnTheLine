# Мелочи из чужих тренажёров: что берём для ДДС

Разбор `docs/competitors/touches.md` (ресерч 16.10). Задачи TC-01…TC-14 стоят в циклах после основных
задач. Что берём, а что нет, решают два фильтра:

- рекомендации организаторов 16.10: интерфейс обучаемого ДДС строго по памятке, а у преподавателя — простота без перегруза;
- эталон `docs/dds_gameplay.md`.

## Берём

| Задача | Цикл | Что |
|---|---|---|
| TC-01 | gameplay | Входящий доклад как настоящий: своя трель, «Старший бригады, служба 101 на связи», «Как приняли?», «Диспетчер, слышите меня?» |
| TC-02 | gameplay | Пропущенный доклад (25 с) и удержание линии вместо сброса |
| TC-03 | gameplay | Должностное лицо: «повторите по буквам» для похожих улиц, номер наряда, нейтральные вопросы, без повторов фраз |
| TC-04 | gameplay | Пробел для разговора, статус микрофона словами, правка распознанного без штрафа |
| TC-05 | gameplay | Чип «Услышано по телефону» и доклад, который меняет задачу |
| TC-06 | gameplay | Три стадии норматива и по одному сигналу на карточку |
| TC-07 | gameplay | Живая смена: фоновые карточки, чужие службы, звонок отдела контроля |
| TC-08 | gameplay | Комментарий («ок», раскладка), без дублей статуса, объяснение неактивных кнопок, обрыв связи |
| TC-09 | ai | Голоса «по телефону», фон, нормализация текста для синтеза |
| TC-10 | ai | Замечание с цитатой, последствием и страницей памятки; нормализация; прокликивание |
| TC-11 | ai | Разбор звонков, лента «+12 с», выполненные рекомендации, повтор проваленного |
| TC-12 | infra | Ход занятия: кто в сети, опаздывающие, зеркало карточки, пауза, сообщение ученику |
| TC-13 | infra | После занятия: «ждут утверждения», оценка ИИ → итоговая с обоснованием, черновик отзыва, тепловая карта, CSV |
| TC-14 | infra | Проверка гарнитуры, пустые экраны, узкий экран, демо одной командой, «что сознательно не сделано» |

## Не берём

- **Всё про заявителя:** паника, «Сынок/Дочка», путает дом, ремарки «(плачет)», «Успокойтесь!» и т. п. Это модуль
  «Оператор 112», он скрыт (рекомендации, п. 5). С пострадавшим ДДС не говорит (п. 8).
- **Изменения вида АРМ обучаемого:**
  - плашки норматива в шапке карточки, цвет приоритета в ленте;
  - вход «логин + пароль + номер АРМ», Alt-ярлыки поверх блоков;
  - красная рамка «ПРОСРОЧКА» вокруг экрана, краснеющие поля.

  Интерфейс обучаемого строго по памятке (п. 6). Срочность — только цвет уже существующего таймера (TC-06).
- **Ползунки весов с пересчётом.** Это инструмент вместо решения: веса задаются один раз.
- **Режимы «блиц» и «марафон», выдвижная шпаргалка, режим проектора, «паспорт готовности».** Не служат обучению
  диспетчера и добавляют экранов преподавателю.
- **Тур по экрану, «прожектор», лестница подсказок.** Это уже GP-23 (подсказки по интерфейсу) — там и решается.
- **PDF-отчёт с подписью.** Документация уже идёт в PDF (GP-22). Отчёт по занятию печатается из браузера (TC-13).
