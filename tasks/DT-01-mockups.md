## Зачем

Прототип капитана ([`docs/dds_training_review/prototype`](../docs/dds_training_review/prototype/README.md)) — один взгляд на учебный слой вокруг АРМ. Чтобы выбрать лучшее, нужны варианты, которые решают ту же задачу по-другому.

## Что сделать

- Пройти прототип целиком (смена, вводные, разминка, пульт, разбор, «Мой путь»), записать, что работает и что нет.
- Посмотреть, что ещё есть у других (разбор капитана, §4) и чего там нет.
- Сделать ещё 2 кликабельных макета с другим интерфейсом учебного слоя. АРМ остаётся копией скриншотов `docs/screenshots/arm_dds/` — меняется только учебный слой вокруг него.
- Положить рядом: `docs/dds_training_review/prototype-b/`, `prototype-c/`, у каждого README «что пробовать».
