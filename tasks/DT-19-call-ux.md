# DT-19. Звонок за один заход: доклад, бригада, статусы, комментарий

- Исполнитель: brikkerdev (Claude, итеративно — цикл ниже)
- День: 12.10
- Зависит от: DT-15…DT-18 (`integration/dds-b`)
- Ветка: `feature/dt-19-call-ux` → `integration/dds-b`

## Зачем

Обучаемый говорит доклад одной фразой, как живой человек, — и служба его понимает; с бригадой
можно поговорить; статус ставится сразу, без поиска; понятно, что писать в комментарии.
Это ровно то, что проверяется на этапе.

## Промпт цикла

Повторять, пока в «Готово, когда» есть пустые пункты:

1. Взять первый пустой пункт. Сначала тест, который падает на фактах из журнала ниже.
2. Минимальная правка; `uv run pytest packages/evalcore`, `pnpm -C apps/web test`, `typecheck`.
3. Пересобрать стенд dt-demo из этой ветки и пройти звонок на стенде (trainee05, не trainee03).
4. Коммит, пуш, слить в `integration/dds-b`, отметить пункт.
5. Вкус (вид колонки связи, сколько кнопок оставить) не решать — скриншот и вопрос
   пользователю, пункт помечается «ждёт пользователя», цикл идёт дальше.

Не трогать: `down -v`, чужие контейнеры, старые worktree. Дизайн не придумывать — АРМ со
скриншотов и модуль 112.

## Факты: звонок 12.10 22:37, карточка 70005312 (журнал стенда)

1. **Доклад в 102: 6 фраз, 1:48, засчитано 0 из 4 с первой фразы.** Первая фраза
   (распознано): «Служба СТО-2 Каширское шоссе 26 Столкнулись два лихых автомобиля, в одном
   зажат водитель в сознании выйти не может…». В ней служба, адрес, повод и обстановка.
   Не засчитано, потому что:
   - «СТО-2» — так распознано «сто два»; «служба 102» ждётся цифрами;
   - повод ищется только словами класса «ДТП с заблокированными», а пересказ описания
     («столкнулись», «зажат») не считается;
   - «что изменилось» — только слова решения; «отправляю» (несовершенный вид) не в словаре;
   - громкость −41 дБ при пороге −40 — «тихо».
   Служба после каждой фразы спрашивала одну следующую часть — отсюда пять кругов.
2. **Бригаде нечего сказать.** «Говорить» есть, только когда бригада задаёт вопрос.
3. **Статусы.** Строка статуса скрыта и открывается карандашом или Alt+Z (DT-17). Раньше
   всегда была на виду.
4. **Комментарий.** «Ключевые сведения» ищет во всех комментариях происшествие, решение и
   пострадавших. Нигде на экране этого нет; обучаемый спрашивает «где и когда его писать».
5. **Разбор врёт.** «Доклад по телефону — отлично 100 %» рядом с «доклад не сделан»; «без
   того, что изменилось» трижды подряд.
6. **Статус по докладу бригады.** Бригада сказала «работы не проводили, участники уехали» —
   обучаемый поставил «Проведение работ → Работы завершены», эталон — «Отказ от выполнения работ».

## Готово, когда (DoD)

- [x] Первая фраза из факта 1 распознаётся как «кто вы + адрес и повод + что изменилось»;
      служба спрашивает только номер карточки (тест evalcore на этот текст).
- [x] Неполный доклад — один вопрос службы обо всём недостающем, а не по части за раз.
- [x] Строка статуса всегда видна в открытой карточке (решение пользователя 12.10).
- [x] У комментария видно, что в нём ждут (происшествие, решение, пострадавшие).
- [x] С бригадой можно говорить в любой момент разговора; бригада отвечает на сказанное.
- [x] Разбор: строки доклада другого звонка помечены «Другой звонок — …», повторы — «(3 раза)».
- [ ] Колонка связи во время разговора: скриншот показан пользователю (вкус) — ждёт пользователя.
- [x] e2e и юнит-тесты зелёные, кроме известных старых падений; стенд пересобран.

## Заметки

- [ASSUMPTION] Звонок направленной бригаде своей службы засчитывает обязательный звонок целиком
  (так решено до DT-19: «позвоните бригаде по прямому номеру»). Поэтому «Доклад по телефону —
  100 %» при неудачном докладе в 102 — не ошибка балла; ошибкой было, что строки другого звонка
  стояли без пометки. Если доклад в 102 должен быть обязательным отдельно — это решение по
  сценарию, не по коду.
- Факт 6 (статус по докладу бригады) — не баг: бригада сказала «работы не проводили». Теперь её
  можно переспросить «доложите обстановку» — она повторит доклад.
- «Отправляю бригаду» засчитывается как «что изменилось», «сто два» — как служба 102; повод —
  пересказом двух слов описания карточки (не адреса). Всё это — evalcore/report.py.
- Стенд: что услышало распознавание — `docker logs dt-demo-api-1 | grep "Голосовой доклад"`.
- DT-20 (в этой же ветке): линии как в прототипах A и B — вызовы всех карточек в колонке
  связи, «Ответить» сбрасывает текущий разговор, бригада кладёт трубку сама после 6 с тишины.
  Несколько линий сразу бывает со ступени 4 (две карточки) и когда направлено несколько бригад;
  в ступени 3 карточка одна — сколько карточек давать в ступенях, решает «Мой путь».
