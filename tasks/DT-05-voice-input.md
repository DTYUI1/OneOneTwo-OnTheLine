# DT-05. Нормальный голосовой ввод

- Исполнитель: brikkerdev
- День: 6–7
- Зависит от: —
- Issue и статус: #68

## Зачем

Диспетчер на деле говорит голосом. Сейчас голос пишется, но содержание не понимается; в ветке `112-call2` голос заменён вариантами ответа.

## Что сделать

- Решено 02.10: и голос, и варианты ответа (decisions). Варианты ответа
  берём из рабочего дерева `112-call2` (brikkerdev): окно разговора, 4 варианта доклада службе,
  оценка полноты по `report_choices`. Микрофон из того дерева удалён — его возвращаем.
- Варианты — запасной путь: ответ вариантом помечается в разборе и оценивается ниже голоса;
  у преподавателя переключатель «только голос» (уточнение капитана, [decisions](../docs/decisions.md)).
- Варианты доклада — по порядку памятки ДДС, с. 32 (сделано в DT-11, 08.10).
- Распознавание локально, без интернета и GPU (faster-whisper в worker уже есть) — проверить скорость на 23 местах.
- Распознанный текст засчитывается по смыслу (ключевые сведения), а не по факту звонка.

## Заметки

- 06.10 (часть 2, не закоммичено): голос возвращён рядом с вариантами.
  - Окно разговора: крупная кнопка «Говорить» → «Закончить доклад» на виду; варианты свёрнуты
    за ссылкой «Ответить вариантом» и раскрываются сами после двух нераспознанных фраз или когда
    голосом нельзя (нет микрофона, доступа, распознавания на сервере — сообщение по-русски).
    `apps/web/src/arm/softphone/{useVoiceReport,voiceReport,phraseRecorder}.ts`.
  - Распознавание: `POST /calls/{id}/voice-report` (`apps/api/app/api/voice_report/`) →
    faster-whisper в сервисе `stt` (small, int8, CPU, beam 1 — как было). Фраза идёт из api
    напрямую, не через очередь worker: служба отвечает в том же разговоре (так же сделан
    вопрос оператора 112). Сервис теперь возвращает и уверенность (`deploy/stt/server.py`).
  - По смыслу: `evalcore/report.py` сводит текст к виду доклада по ключевым сведениям
    комментария (суть → адрес с домом → пострадавшие и силы) — та же шкала, что у вариантов.
  - Пусто или уверенность < `STT_MIN_CONFIDENCE` (0,45) — служба «Не расслышал, повторите.»
  - Оценка: в отбое `report_modes` (`voice`/`option`) и `voice_failures`; доклад вариантом —
    доля `report_choice_factor` (по умолчанию 0,5) от голосового; в разборе «голосом» / «ответ
    вариантом», «голос не распознан: N, предложены варианты ответа».
  - Преподаватель: «Доклад только голосом» и «Доклад вариантом, доля балла» в настройках
    занятия (`SettingsFields` — та же форма у админа и при создании занятия).
  - Контракт (это `contract:` PR): `call_hangup.report_modes`, `voice_failures`;
    `Settings.voice_only`, `report_choice_factor`; путь `/calls/{id}/voice-report` и схема
    `VoiceReport`. Поля только добавлены, старые события и настройки валидны.
  - `deploy/`: api получил `STT_*` (без них распознавание в api было выключено и у оператора
    112); в образе `stt` закреплён `av==15.1.0` — с PyAV 19 faster-whisper 1.2.1 падает на
    `av.open(metadata_errors=…)`, свежая сборка не распознавала бы ничего.
