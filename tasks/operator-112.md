### OP-11. Имя обучаемого в шапке

Зачем: в настоящем АРМ в шапке видно, кто завёл карточку («Опер. <ФИО>, АРМ 4, УМЦ 0 п»). Сейчас
строка без имени — обучаемый и преподаватель на проекторе не видят, чья это попытка.

- Решение капитана: отдельная строка с ФИО обучаемого **выше** «Опер., АРМ …», саму строку
  «Опер., АРМ …, УМЦ 0 п» не трогаем (`apps/web/src/operator/OperatorPage.tsx`, блок `styles.incident`).
- Без обрезки на 1366×650 и 1366×768: шапка фиксированной высоты, четвёртая строка не должна
  выталкивать таймер.

### OP-12. Адрес целиком в сохранение и оценку

Зачем: оператор спрашивает подъезд, этаж и код домофона, вписывает их — а в карточку они не попадают.
`save.ts` отправляет только 7 полей (субъект, округ, район, улица, дом, корпус, квартира); объект,
стр/соор, подъезд, этаж, код и описательный адрес теряются. У мальчика в лифте ориентир пишется как
раз в описательный адрес.

- `apps/web/src/operator/save.ts`, `AddressInput` в `apps/api/app/operator/router.py`.
- Оценка адреса (`evaluation.py`, `contracts/operator/evaluation.md`): новые поля сверяются,
  только если заявитель их называет (`named_address_fields`), как округ и район; веса не меняем.
  Описательный адрес — по ориентиру сценария (синонимы, как факты описания).
- Карточка для ДДС: адрес в `contracts/card.schema.json` без этих полей — `contract:` PR и согласовать
  с brikkerdev (DT-03, DT-04: что из этого видит диспетчер в АРМ ДДС).

DoD:
- [x] pytest: подъезд, этаж, код, описательный адрес сохраняются и попадают в разбор; не названное —
  без штрафа; ориентир ребёнка засчитан;
- [x] vitest `save.test.ts`; e2e `operator-full` вписывает подъезд и этаж;
- [x] `validate_contracts.py`, `export_openapi --check` чисто.

### OP-13. Статус заявителя

Зачем: по инструкции «ФИО заявителя», «Статус заявителя», описание и «Пострадавшие» — обязательные
для корректной обработки (п. 4.1, 5.3). Сейчас список статуса неактивен.

- Шесть статусов из инструкции: очевидец, пострадавший, родственник, знакомый, ребенок, участник.
- Верный статус — поле `caller.status` у каждого из 4 сценариев (девушка — очевидец, жена —
  родственник, мальчик — ребенок, водитель — участник/очевидец — проверить по сценарию).
- Сохраняется; в разборе — пояснение в «Работе с заявителем» без баллов (веса не трогаем).

DoD:
- [x] выбор статуса с клавиатуры и мышью; значение в попытке и в разборе;
- [x] pytest и vitest; e2e `operator-full` выбирает статус.

### OP-14. Неработающие кнопки

Зачем: на экране кнопки как в настоящем АРМ, но нажать нельзя (подсказка «В тренажёре не
используется» видна только при наведении). Решение капитана: каждая либо работает, либо по
нажатию объясняет, что делает в настоящем АРМ.

Для «объяснить» — одно окно-подсказка у кнопки: «В АРМ 112: …» и «В тренажёре: не нужно, потому
что …», ссылка на раздел справки «?». Кнопка нажимается (не `disabled`), с клавиатуры тоже.

### OP-15. Горячие клавиши

Зачем: кейсодержатель учит им операторов (Q15), в настоящем АРМ работа идёт с клавиатуры. Сейчас в
модуле работает только Esc.

- Раздел 13 инструкции: Alt (зажатие) — подсказки по клавишам; Alt+F1/F2/F3 — телефоны; Alt+Q —
  заявитель; Alt+A — адрес; Alt+P — пострадавшие; Alt+N — нет контакта / срыв звонка; Alt+T — «что
  случилось»; Alt+O — описание; Alt+Z — службы; Alt+1… — опросные карты; Alt+S — сохранить; Esc; Tab.
- По `event.code`, а не по букве: в инструкции «Alt + А» — русская раскладка.
- Не перехватывать то, что браузер не отдаёт (Alt+F, Alt+D и т. п. в списке нет — проверить в Chrome и
  Firefox); в справке «?» — таблица клавиш.

DoD:
- [x] e2e: звонок от «Принять вызов» до «сохранить» только с клавиатуры;
- [x] Chromium и Firefox; подсказки по зажатому Alt не сдвигают вёрстку.

### OP-18. Единая адресная строка с подсказкой улиц

Зачем: в настоящем АРМ адрес вводится одной строкой, система предлагает варианты (Яндекс, ФИАС) и
сама ставит округ и район (п. 4.3). С подсказкой ловушка «Дубнинская / Дубининская» становится
настоящей: обе улицы есть в Москве, легко выбрать соседнюю строку.

- Источник улиц — офлайн: в репозитории справочника нет (`data/streets.csv.gz` не поставлен).
  Варианты: ФИАС/ГАР или OSM по Москве в `streets.csv.gz` (проверить лицензию и размер). Запасной
  путь, если справочника нет: улицы сценариев и похожие на них (обе Дубн…), округ и район
  из сценария.
- Выбор варианта заполняет улицу, дом, округ, район; поля ниже остаются для правки руками.
- Оценка адреса не меняется (OP-12).
